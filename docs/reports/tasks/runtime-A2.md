Notes for neighbours:
- `TenantConfig.hours` is normalised by the validator to all seven weekday keys (missing days become `[]`) with each span a `tuple[str, str]` of `"HH:MM"` local wall-clock strings. Task 3's `BusinessCalendar` can index `cfg.hours["mon".."sun"]` without a `.get`.
- Every model is `frozen=True`, so `TenantConfig` and its sub-models are immutable and compare by value; `config_from_json(config_to_json(cfg)) == cfg` and `load_bundle(export_bundle(...))` both round-trip exactly (verified). Do not mutate a config in place — build a new one with `model_copy(update=...)`.
- `load_bundle` wraps every pydantic `ValidationError` in a plain `ValueError` whose message starts with `invalid bundle <path>:`. Task 7's registry and Task 14's CLI should surface that message; Task C3's `PUT /internal/tenants/{id}/config` needs the field paths, so it should call `TenantConfig.model_validate` directly rather than `load_bundle` to keep the 422 field detail.
- `Scripts` has 10 required keys (`disclosure, clinical, human_request, complaint, payment, captured, link_sent, link_captured, cannot_complete, goodbye`) and `clinical` must contain `911`. Any test fixture that constructs `Scripts` inline must supply those; prefer `load_bundle(runtime/tenants/skincentrix)` or `cfg.scripts.model_copy(update=...)`.
- Not enforced in code, and no later task in this plan enforces it either: `docs/reference/tenant-config.md` also says *"disclosure must say it is an AI in the first two sentences"* and *"every script that mentions the team must keep `{confirm_by}`"*. The second rule cannot be applied mechanically (the authored defaults `link_sent` and `takeover_notice` mention the team with no `{confirm_by}`), so I did not add a validator for either rather than risk breaking fixtures in tasks running in parallel. Flagging for the orchestrator: if the disclosure rule should be machine-checked, it belongs in `Scripts._no_completion_words`'s neighbourhood and should be added in one place with the affected tasks notified.
- The Skincentrix bundle carries the plan's three `UNVERIFIED` markers as comments (hours from a third-party listing, `transfer_number`, `after_hours_clinical_contact`). `voice_numbers: []` and `sms_from_number: null` stay empty until the founder's Telnyx purchase.
