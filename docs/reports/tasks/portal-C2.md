## A bug the e2e found

`PendingInvitationRedirect` forgot the parked token *before* navigating to the invitation. The login page's own "you are signed in, go to /app" redirect and this one run in the same React commit, and the last navigation wins, so roughly half the time the person landed on `/app` with the token already erased and the invitation silently lost. The token is now kept until `/invite/:token` is actually reached and forgotten there. Evidence: `waitForURL("**/invite/**")` failed in two consecutive full-suite runs and passed when `orgs.spec.ts` ran alone; after the fix, two consecutive full-suite runs are 16/16.
