## Findings (most severe first)

- [major, fixed `841df3f`] `runtime/spatalk/ops/loop_guard.py` `log_loop_guard_alert` — alerting invariant. The loop guard wrote an `alert_log` row directly, with no `sent_at`, so it was never emailed or texted and never deduplicated: a number stuck in a forwarding loop alerted once per ring. Now routed through E7 `notify` (one row, one email, one ops text per tenant and number in the dedup window); test `test_a_second_loop_call_inside_the_window_raises_no_second_alert`.
- [major, fixed `841df3f`] `runtime/spatalk/voice/pipeline.py:62` — runbook promise. `DeepgramFluxSTTService` was built without `mip_opt_out=True` although `docs/runbooks/accounts-and-env.md` states the runtime opts out of Deepgram training. Flag added.
- [major, fixed `841df3f`] `runtime/spatalk/voice/pipeline.py` `make_tts` — provider swappability (non-negotiable 4). The founder's single-vendor decision (`TTS_PROVIDER=soniox`) had no branch and fell through to Inworld. `SonioxTTSService` with `tts-rt-v2` and `SONIOX_VOICE` added; `SONIOX_VOICE` documented in `.env.example` and `api-surface.md`. Live latency of the Soniox voice is still unmeasured (bake-off item).
- [major, fixed `841df3f`, size unverified] `runtime/Dockerfile` — deploy. QA gate C measured the runtime image at 10.1 GB, 5.2 GB of it CUDA pulled by the default torch wheel. The image now installs the CPU wheels first so pipecat's pin is satisfied. The new image has not been built here; the founder's deploy step will show the size.
- [major, fixed `fc392cb`] `runtime/spatalk/brain/rules.py` `rules_gate` — honesty of the hand-off. "Am I talking to a real person?" matched `real person` in the human-request lexicon and produced the band-3 hand-off script, a false promise of a callback. The identity clause is now blanked before that lexicon runs, and `prompt.py` tells the model to answer the question honestly in one sentence and offer a person. Tests in `tests/test_rules.py`.
- [minor, fixed `841df3f`] `runtime/spatalk/brain/renderer.py` escalation branch — fixed wording per channel. The clinical script's phone wording ("call you back at this number", "hang up and call 911") went out verbatim on SMS, web chat and DMs. New `Scripts.clinical_text` (validated for the 911 sentence like `clinical`) is rendered on every non-voice channel; Skincentrix bundle and `tenant-config.md` carry it.
- [minor, open] `runtime/spatalk/ops/retention.py` — retention coverage. `meta_events` (webhook dedup ids: event id, tenant, provider, kind, received_at; no payload) is never pruned. Harmless for privacy, unbounded growth at scale. One `delete` older than `retention_days` in the retention job closes it.
- [minor, open] `runtime/scenarios` on Windows — promptfoo's Python assertion runner crashes on this machine and a crashed grader is counted as a product failure (gate C). Run the suite on the VPS or in WSL; not a product defect.
- [minor, open] Portal end-to-end suite cannot seed a runtime from the containers without `RUNTIME_SEED_COMMAND` (gate C). Test infrastructure, not product.
- [minor, open] `npx tsc --noEmit` in `edge/sms-worker` fails on a clean checkout (gate C); passes here with `node_modules` present. Likely a missing `npm ci` step in the CI job rather than code.
- [note] `runtime/spatalk/brain/driver.py:22`, `tools.py:3` import `FunctionSchema`/`ToolsSchema` from `pipecat.adapters.schemas`. These are framework schema types, not a vendor SDK; acceptable, recorded so nobody reads it as a breach of invariant 5.
